# Login Authentication System

A simple Login Authentication System built using HTML, CSS, and JavaScript. This project allows users to register, log in, access a secure dashboard, and log out.

## Features

- User Registration
- User Login
- Secure Dashboard Access
- Logout Functionality
- Local Storage Authentication
- Responsive User Interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Open the project in your browser.
2. Register with a username and password.
3. Log in using the registered credentials.
4. Access the dashboard after successful login.
5. Click Logout to end the session.

